Privacy policy

darker-ages-uploader. Last updated 7 September 2026.

darker-ages-uploader is a private tool used by one person to publish videos to their own YouTube channel and to read that channel's analytics. It has no other users and collects no information from the public.

Information accessed

When the operator signs in with their Google account, the application receives an access token limited to these permissions:

  • Uploading videos to the operator's YouTube channel
  • Managing the title, description, tags, thumbnail and visibility of those videos
  • Reading analytics for that channel, including views, watch time and traffic sources

The application does not request access to email, contacts, files, or any Google service beyond YouTube.

Storage

The authorisation token is stored only on the operator's own computer so the tool can run without signing in again. It is never transmitted to a server, never shared, and never sold. Video files and analytics data are handled on that same computer and are not uploaded anywhere except to YouTube itself.

Sharing

No data is shared with any third party. There is no advertising, no analytics service, and no tracking in this application.

Retention and removal

The stored token remains until the operator deletes it or revokes access. Deleting the local credential file removes it immediately.

Revoking access

Access can be withdrawn at any time from the Google account permissions page at myaccount.google.com/permissions.

YouTube API Services

This application uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Changes

Any change to this policy will be published on this page with a revised date.
